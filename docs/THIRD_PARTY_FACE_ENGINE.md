## Body/neck tracking

Necklaces additionally use `@mediapipe/tasks-vision@0.10.32` (Apache-2.0),
self-hosted by `prepare-face-engine.mjs`. No models or camera frames are sent
outside the device. The Apache license is shipped at
`/models/tracking/LICENSE.txt` and linked in the necklace preview.

The checked-in `pose_landmarker_lite.task` combines the Google BlazePose Lite
landmarker and detector from the Apache-2.0 npm package
`@mediapipe/pose@0.5.1675469404`. `pose_solution_packed_assets_loader.js` identifies
its entire packed-assets data file as `pose_detection.tflite`. Model weights
are unchanged; Tasks input normalization metadata is added (detector mean/std
127.5/127.5, landmarker 0/255) and the two files are wrapped in a deterministic
uncompressed task archive. This is a repackaged legacy Google model, not an
unchanged download of the newer Google Tasks model bundle.

To reproduce: `npm pack @mediapipe/pose@0.5.1675469404` and extract it. Obtain
`schema_py_generated.py` and `metadata_schema_py_generated.py` from
`tflite-support==0.4.4`'s `tensorflow_lite_support/metadata` directory (only
pure Python schema files are used), install `flatbuffers==25.12.19` and `numpy==2.3.5`, then run:

```bash
python scripts/repack-pose-model.py --source-dir /path/to/extracted/package \
  --schema-dir /path/to/tensorflow_lite_support/metadata \
  --output public/models/tracking/pose_landmarker_lite.task
```
