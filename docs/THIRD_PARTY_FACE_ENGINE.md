## Body/neck tracking

Necklaces additionally use `@mediapipe/tasks-vision@0.10.32` (Apache-2.0),
self-hosted by `prepare-face-engine.mjs`. No models or camera frames are sent
outside the device. The Apache license is shipped at
`/models/tracking/LICENSE.txt` and linked in the necklace preview.

The checked-in `pose_landmarker_lite.task` combines the Google BlazePose Lite
landmarker and detector from the Apache-2.0 npm package
`@mediapipe/pose@0.5.1675469404`. `pose_solution_packed_assets_loader.js` identifies
its entire packed-assets data file as `pose_detection.tflite`. Model weights
are unchanged; Tasks input normalization metadata is added (detector mean/std
127.5/127.5, landmarker 0/255) and the two files are wrapped in a deterministic
uncompressed task archive. This is a repackaged legacy Google model, not an
unchanged download of the newer Google Tasks model bundle.

To reproduce: `npm pack @mediapipe/pose@0.5.1675469404` and extract it. Obtain
`schema_py_generated.py` and `metadata_schema_py_generated.py` from
`tflite-support==0.4.4`'s `tensorflow_lite_support/metadata` directory (only
pure Python schema files are used), install `flatbuffers==25.12.19` and `numpy==2.3.5`, then run:

```bash
python scripts/repack-pose-model.py --source-dir /path/to/extracted/package \
  --schema-dir /path/to/tensorflow_lite_support/metadata \
  --output public/models/tracking/pose_landmarker_lite.task
```

Archive SHA256: `6b2ae41ee1ea77684c183ad10b6c10c5a9ae8704f8532ae1db30cf6d1dfe5cfb`.


The additional `selfie_segmenter.tflite` comes from Google's Apache-2.0
`@mediapipe/selfie_segmentation@0.1.1675465747` npm package. We retain its
weights and add Tasks input normalization metadata (mean 0, std 255).
It runs with the CPU ImageSegmenter in the same bounded worker. Only derived
landmarks and contour coordinates leave the worker; camera frames remain local.
The bundled Apache license also covers this model.

Reproduce with the same schema files and Python dependencies above:

```bash
npm pack @mediapipe/selfie_segmentation@0.1.1675465747
# Extract the archive, then:
python scripts/repack-selfie-model.py --source /path/to/package/selfie_segmentation.tflite \
  --schema-dir /path/to/tensorflow_lite_support/metadata \
  --output public/models/tracking/selfie_segmenter.tflite
```

Normalized model SHA256:
`0859a70e2e3e9ab40f1dced1c93ee2cdf8fb43abffe7a010408dd067c7158e98`.

## Independent hand tracking

`hand_landmarker_lite.task` repackages Google's Apache-2.0
`@mediapipe/hands@0.4.1675469240` npm models. The package's packed-assets loader
identifies bytes 2341291–4326731 as `palm_detection_lite.tflite`; the second model
is `hand_landmark_lite.tflite`. Input normalization metadata (mean 0, std 255)
is added without changing model buffers/weights, and both models are placed in
a deterministic uncompressed Tasks archive. This is a legacy model repackaging,
not the current Google downloadable HandLandmarker bundle.

Reproduce with the same schema/Python dependencies documented above:

```bash
npm pack @mediapipe/hands@0.4.1675469240
# Extract the package, then:
python scripts/repack-hand-model.py --source-dir /path/to/package \
  --schema-dir /path/to/tensorflow_lite_support/metadata \
  --output public/models/tracking/hand_landmarker_lite.task
```

SHA256: `c42df3382c16edddf9f2ee8e1f6ca7c4f2f060fe3fd783d7b38915e74787125b`.
The existing `/models/tracking/LICENSE.txt` supplies Apache-2.0 terms.
